# Twitter / X Post Creator

A TypeScript Agent Tool for creating text posts using the X API v2.

## Features

- Create text posts using X API v2
- Environment-based authentication
- Input validation
- Structured API error handling
- MCP-compatible metadata

## Requirements

An X Developer account and an application with permission to create posts.

A User Access Token is required.

## Environment Variables

| Variable | Required | Description |
| --- | --- | --- |
| `X_USER_ACCESS_TOKEN` | Yes | OAuth user access token with permission to create posts |
